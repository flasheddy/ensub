# Ensub Offline Lexicon

`lexicon-v1.sqlite3.zst` is generated by `ensub-lexicon-builder` from Open
English WordNet 2025 definitions and the CMUdict data distributed with
`cmudict-fast` 0.8.0. Normal Ensub builds embed this generated artifact and do
not download dictionary data.

See `PROVENANCE.toml` and `THIRD_PARTY_LICENSES/` for source versions,
checksums, and redistribution notices.

The generated database contains 32,463 lexemes, 49,207 surface forms, and
78,463 ranked senses. Ensub transforms the sources by filtering incomplete
entries, deriving inflected forms, converting CMUdict ARPAbet pronunciations
to broad General American IPA, and packaging the result as SQLite/Zstandard.
